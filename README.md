# DayFlow

**Умный календарь и планировщик дня для Windows** — приложение, которое само всё напоминает, чтобы вы ничего не забыли и всё шло по графику.

## Возможности

- 📅 **Календарь (2D)** — месяц, выбранный день, расписание по часам
- 🧊 **3D-хроника недели** — объёмная визуализация событий по дням и времени (вращение мышью, масштаб колесом, сдвиг правой кнопкой)
- 🔔 **Напоминания** — всплывающее окно + звук + системное уведомление Windows, с кнопкой «Отложить на 10 минут»
- 🔁 **Повторяющиеся события** — каждый день / неделю / месяц
- ⭐ **Приоритеты и категории** — работа, личное, здоровье, учёба
- ✅ **Задачи** — чек-лист с прогрессом
- 🚀 **Автозапуск** — включается вместе с Windows и живёт в системном трее (закрытие окна сворачивает в трей)

## Установка и запуск

1. Распакуйте `DayFlow-Windows-x64.zip`
2. Запустите **`DayFlow.exe`**
3. Готово. Приложение само пропишется в автозагрузку (отключить можно в ⚙️ Настройках или в меню иконки в трее)

> Данные хранятся локально на вашем компьютере — ничего не отправляется в интернет.

## Сборка из исходников

Требуется: Linux/macOS с `npm`, `zip`, `tar`.

```bash
./build.sh                       # скачает рантайм NW.js из npm и соберёт релиз
# или с готовым архивом рантайма:
./build.sh nwjs-binaries-win-x64-0.87.0-sdk.tgz
```

Результат: `release/DayFlow-Windows-x64.zip`.

Рантайм берётся из npm-пакета `@nwjs-binaries/win-x64` (полный Chromium+Node — не требует других CDN).

## Структура

- `renderer/index.html`, `styles.css` — интерфейс
- `renderer/app.js` — логика (календарь, задачи, напоминания, хранение)
- `renderer/three-scene.js` — 3D-хроника недели
- `renderer/nw-bridge.js` — мост с рабочим столом (трей, автозапуск через реестр, уведомления)
- `vendor/` — Three.js (без сети)
- `assets/` — иконки
- `smoke-test.js` — автотест логики интерфейса (`npm i jsdom && node smoke-test.js`)
