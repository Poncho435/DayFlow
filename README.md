# DayFlow

**Умный календарь и планировщик дня для Windows** — приложение, которое само всё напоминает, чтобы вы ничего не забыли и всё шло по графику.

## Возможности

- 📅 **Календарь (2D)** — месяц, день, расписание по часам
- 🧊 **3D-хроника недели** — объёмная визуализация событий по дням и времени (вращение, масштаб, сдвиг)
- 🔔 **Напоминания** — всплывающие окна + звук + системные уведомления Windows
- 🔁 **Повторяющиеся события** — каждый день / неделю / месяц
- ⭐ **Приоритеты и категории** — работа, личное, здоровье, учёба
- ✅ **Задачи** — чек-лист с прогрессом
- 🚀 **Автозапуск** — включается вместе с Windows и живёт в трее

## Установка

1. Скачайте `DayFlow-Setup-1.0.0.exe` и запустите установщик
   *(или используйте портативную версию `DayFlow-Portable-1.0.0.exe` — без установки)*
2. Готово — DayFlow появится в меню «Пуск» и на рабочем столе
3. Приложение автоматически добавится в автозагрузку (можно отключить в «Настройках»)

## Сборка из исходников

```bash
npm install
npm run dist:win     # соберёт .exe в папку release/
npm start            # запуск в режиме разработки
```

## Структура

- `main.js` — главный процесс Electron (окно, трей, автозапуск, уведомления)
- `preload.js` — мост между процессами
- `renderer/` — интерфейс (HTML/CSS/JS + 3D-сцена)
- `vendor/` — Three.js (без сети)
- `assets/` — иконки

> Данные хранятся локально (LocalStorage) — ничего не отправляется в интернет.
